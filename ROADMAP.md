# Sonora Roadmap

Product purpose: a fast audition and editing player with loudness metering —
helping audio editors, sound designers, and anyone who works with professional
audio move quicker from hearing a file to shaping it.

This document lists planned directions. It is not a schedule and does not
describe commercial terms.

## Sonora Free (current → 1.0)

- Folder-based audition, file list, Browser / Details
- Waveform, spectrogram, waterfall and related views
- Level meters and loudness analysis
- File management, batch rename, convert / export, list CSV
- Multilingual UI and customizable hotkeys
- Voluntary donations support ongoing Free maintenance

## Sonora Pro (planned capabilities)

Additional directions beyond the Free player experience:

- Batch loudness analysis report CSV export
- CLI for scripting and unattended analysis
- macOS and Linux support
- Audio library database (scan / index for fast find & audition)
- Loop auto-editing (loop-point matching with fade in / fade out)
- ASIO output
- Selection export with sample rate / bit depth / channel options
- Pitch
- Recording to WAV
- Batch targets (copy / move into preset folders)

Items may ship in different order. Names and packaging can change.
