User Manual

Sonora 使用说明书

Sonora 是带响度分析的快速试听与剪辑播放器，帮助音频编辑、声音设计师以及需要专业音频支持的人，更快完成「听到 → 看清 → 轻剪」。

简介

以文件夹为单位工作，而不是强制建库。打开目录后即可试听采样、分轨与成片，同时观察波形、频谱、电平与响度，并完成轻量导出与文件整理。

  • 当前公开版本为 Sonora Free（Windows x64）
  • 音频与分析均在本地完成，默认不上传你的素材
  • 产品定位是提效播放器，不是完整 DAW 或素材库套件

安装与启动

安装包

从 GitHub Releases 下载 Sonora_*_x64-setup.exe 并运行。安装程序可注册常见音频扩展名的文件关联与图标。

便携版

直接运行 Sonora_*_portable.exe（或 sonora.exe），无需安装。便携版通常不写入文件关联。

SmartScreen

当前构建尚未代码签名。若 Windows 提示「Windows 已保护你的电脑」，选择 更多信息 → 仍要运行。

打开方式

打开与浏览

  • 工具栏 Parent folder 返回上级；文件夹历史可打开最近目录
  • Locate（Ctrl+L）在 Browser / 列表中定位当前播放文件
  • 列表上方搜索框可过滤当前文件夹内的文件名
  • 列头可排序；列菜单可调整显示列与顺序（水平滚动支持宽列表）
  • 状态栏 SCM / DCM：单击播放 / 双击播放

播放

走带

上一首 / 播放暂停 / 停止 / 下一首。空格切换播放暂停；左右方向键微调位置；上下方向键调节音量。

播放模式

  • Sequential / Shuffle：顺序或随机
  • Loop One：单曲循环
  • Stop after current：播完当前文件后停止
  • Keep Position：切换文件时尽量保持播放位置（便于对比 takes / 混音版本）

控件作用

波形与可视化

工具栏可视化按钮：单击循环模式，右键直接选择。也可按 F12 循环。

模式说明
Waveform整文件波形总览，点击跳转，拖动创建选区
Spectrogram频谱图；Ctrl + 滚轮缩放
3D Waterfall实时频谱瀑布
Log / Lin Analyzer对数 / 线性实时频率分析
Bars频段柱状显示
Oscilloscope示波器视图

可在 Preferences / Interface 中开关 Show cursor readouts（光标时间与频率读数）。

电平与响度

  • 输出表：单击循环 Peak / RMS / K-14 / VU，右键直接选择
  • 相位 / 平衡：立体声关系观察（可在界面模块中开关）
  • 文件响度：Integrated LUFS、LRA、True Peak 等可显示在列表与 Details
  • 右键文件 → Refresh Loudness 可对选中项重新分析（长视频可能跳过）

选区 · Cue · A-B

选区

在波形上拖动创建选区；可循环选区、复制到 A-B、或导出为文件（WAV / float WAV / MP3 / OGG / AAC 等，含增益与淡入淡出选项）。也可拖拽选区句柄到资源管理器或 DAW。

Cue

工具栏添加 Cue（左键添加，右键打开 Cue 相关选项）。Cue 按文件保存，可在 Cue 间跳转。

A-B 循环

在播放头设置 A / B，开启 A-B Loop 重复该区间；可从当前选区一键写入 A-B。

文件与批处理

列表操作

剪切 / 复制 / 粘贴、全选、反选、删除（回收站）、重命名（F2）、在资源管理器中显示等。多选时菜单项会显示数量后缀。

批量工具

  • Batch Rename：规则重命名，带预览与撤销
  • Export / Convert：批量转码
  • Export CSV：导出当前列表字段（含已分析的响度等）

偏好设置（Ctrl+P）

Sound

  • 输出设备（WASAPI 等）
  • 采样率：Auto 或固定值
  • 声道：Auto / 1 / 2 / 5.1 / 7.1
  • 独占模式等选项
  • ASIO 在 Free 中为占位（Pro 能力方向）

Interface / File List / Hotkeys

  • 主题：Light / Dark / Follow system
  • 字号、密度、模块显隐、光标读数
  • 列表列与行为相关选项
  • Hotkeys：查看并自定义快捷键，自动检测冲突

设置保存在本机，不随安装包分发。

常见问题

为什么安装/运行被拦截？

尚未代码签名。按 SmartScreen 提示「更多信息 → 仍要运行」即可。

响度列为什么是空的？

响度需分析后才有值。可等待后台分析，或对选中文件使用 Refresh Loudness。过长视频可能被跳过。

数据会上传吗？

试听与分析在本地进行。官网仅用于下载与说明；捐助跳转到你配置的外部收款页。

如何反馈问题？

使用 GitHub Issues。
