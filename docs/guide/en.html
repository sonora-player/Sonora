User Manual

Sonora documentation

Sonora is a fast audition and editing player with loudness metering — helping audio editors, sound designers, and anyone who works with professional audio move quicker from hearing a file to shaping it.

Overview

Work by folder, not a mandatory library. Open a directory, audition samples or stems, watch waveform / spectrum / level / loudness, and do light exports or file tidy-ups in one window.

  • Public builds are Sonora Free for Windows x64
  • Audio and analysis stay local
  • Built as a productivity player — not a full DAW or asset-library suite

Install & launch

Installer

Download Sonora_*_x64-setup.exe from Releases. The installer can register common audio file associations.

Portable

Run Sonora_*_portable.exe without installing.

SmartScreen

Builds are not code-signed yet. If Windows blocks the app, choose More info → Run anyway.

Interface

  • Browser (F4): drives, places, folder tree
  • File list: filterable/sortable rows with optional loudness columns
  • Details (Alt+Enter): metadata and loudness detail
  • Visualization (F12): waveform and analyzer modes
  • Status bar: version, SCM/DCM, backend, Preferences

Browse folders

  • Parent folder and folder history on the toolbar
  • Locate current file with Ctrl+L
  • Filter box searches names in the current folder
  • SCM plays on single click; DCM requires double-click

Playback

Transport: previous / play-pause / stop / next. Space toggles playback. Arrow keys nudge position and volume.

  • Sequential / Shuffle
  • Loop One
  • Stop after current
  • Keep Position when switching files
  • Dim / Mono / Downmix / Mute / Volume presets (right-click volume)

Visualizations

Cycle with the toolbar button or F12; right-click to pick a mode: Waveform, Spectrogram (Ctrl+wheel zoom), Waterfall, log/lin analyzers, Bars, Oscilloscope. Optional cursor readouts live under Interface preferences.

Meters & loudness

  • Output meter cycles Peak / RMS / K-14 / VU
  • Phase / balance modules can be shown or hidden
  • File loudness (LUFS / LRA / True Peak) appears after analysis
  • Context menu → Refresh Loudness re-analyzes the selection

Selection · Cue · A-B

  • Drag on the waveform to select; loop, copy to A-B, or export
  • Export formats include WAV, float WAV, MP3, OGG, AAC with gain/fades
  • Add cues from the toolbar; jump between them
  • Set A/B at the playhead and enable A-B Loop

Files & batch tools

  • Cut / copy / paste, rename, delete to Recycle Bin, Show in Explorer
  • Batch Rename with preview and undo
  • Export / Convert for multi-file transcode
  • Export CSV for the current list fields

Preferences (Ctrl+P)

  • Sound: device, sample rate, channels, exclusive mode; ASIO reserved for Pro direction
  • Interface: theme, density, modules, cursor readouts
  • Hotkeys: view and customize accelerators

Settings stay on the local machine.

FAQ

Blocked by Windows?

Unsigned build — use More info → Run anyway.

Empty loudness columns?

Wait for analysis or use Refresh Loudness. Very long videos may be skipped.

Is audio uploaded?

No. Audition and analysis run locally.
