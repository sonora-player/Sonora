User Manual

Sonora documentation

Sonora is a fast audition and editing player with loudness metering — helping audio editors, sound designers, and anyone who works with professional audio move quicker from hearing a file to shaping it.

Overview

Work by folder, not a mandatory library. Open a directory, audition samples or stems, watch waveform / spectrum / level / loudness, and do light exports or file tidy-ups in one window.

  • Public builds are Sonora Free for Windows x64
  • Audio and analysis stay local
  • Built as a productivity player — not a full DAW or asset-library suite

Install & launch

Installer

Download Sonora_*_x64-setup.exe from Releases. The installer installs for all users to C:\Program Files\Sonora by default and requires Administrator privileges. It can register common audio file associations. Upgrading from an older AppData / current-user install automatically removes the leftover copy so you do not end up with two Sonora entries.

Portable

Run Sonora_*_portable.exe without installing.

SmartScreen

Builds are not code-signed yet. If Windows blocks the app, choose More info → Run anyway.

Interface

  • Browser (F4): drives, places, folder tree
  • File list: filterable/sortable rows with optional loudness columns
  • Details (Alt+Enter): metadata and loudness detail
  • Visualization (F12): waveform and analyzer modes
  • Status bar: version, SCM/DCM, backend, Preferences

Browse folders

  • Parent folder and folder history on the toolbar
  • Locate current file with Ctrl+L
  • Filter box searches names in the current folder
  • SCM plays on single click; DCM requires double-click

Playback & audition logic

Sonora is built for folder-based audition: open a directory and hear files in place — no library import required.

  • Transport: previous / play-pause / stop / next. Space toggles playback.
  • SCM plays on single click; DCM needs double-click (status bar toggle).
  • Sequential / Shuffle / Loop One / Stop after current
  • Keep Position when switching files (for comparing takes / mixes; near EOF it will not carry a near-end position into the next file)
  • Dim / Mono / Downmix / Mute / Volume presets (right-click volume)
  • Double-click an associated file (or drop a file) opens its folder and plays; a second launch focuses the existing window (single instance)
  • Drop a folder to load its list without auto-playing

Visualizations

Cycle with the toolbar button or F12; right-click to pick a mode: Waveform, Spectrogram (Ctrl+wheel zoom), Waterfall, log/lin analyzers, Bars, Oscilloscope. Optional cursor readouts live under Interface preferences.

Meters & loudness

  • Output meter cycles Peak / RMS / K-14 / VU
  • Phase / balance modules can be shown or hidden
  • File loudness (LUFS / LRA / True Peak): default Analyze Visible Rows (follows scrolling); optional Analyze All Files. CSV export always finishes needed loudness fields.
  • File List LUFS button → Loudness safe range: mark LUFS-I and/or LRA (off by default). Green in range, red out; filename yellow when a checked metric fails.
  • Context menu → Refresh Loudness re-analyzes the selection (very long videos may be skipped)

Selection · Cue · A-B

  • Drag on the waveform to select; loop, copy to A-B, or export
  • Export formats include WAV, float WAV, MP3, OGG, AAC with gain/fades (no ffmpeg)
  • Drag-out handle renders a real clip into Explorer / DAW
  • Add cues from the toolbar; jump between them
  • Set A/B at the playhead and enable A-B Loop

Files & batch tools

  • Cut / copy / paste; rename (F2 — refuses to overwrite an existing name); delete with confirmation to Recycle Bin; Show in Explorer
  • Header column dividers make column resize easier to grab
  • Batch Rename: opens with the File List selection checked; Preview Select All / None / Invert; Open folder… / Add File List for files outside the current folder; live preview and undo. Toolbar works even if the folder is empty.
  • Export / Convert for multi-file transcode
  • Export CSV for the current list fields

Preferences (Ctrl+P)

  • Sound: device, exclusive WASAPI, channels; sample rate follows the Windows mixer (ASIO reserved for Pro direction)
  • Interface: theme, density, modules, cursor readouts, taskbar playback indicator
  • File List: SCM/DCM, sticky selection, follow active item, LUFS scan mode, columns
  • Hotkeys: view and customize accelerators
  • Drag: clip folder and export format for drag-out

Settings stay on the local machine. Help → Check for Updates downloads installers from GitHub Releases.

FAQ

Blocked by Windows?

Unsigned build — use More info → Run anyway.

Empty loudness columns?

Wait for analysis (visible rows by default) or use Refresh Loudness. Very long videos may be skipped. Enable Loudness safe range from the LUFS button if you want green/red marking.

Is audio uploaded?

No. Audition and analysis run locally.
