Folder preview · meters · light editing in one window.

Hear fast

Open a folder and audition samples or stems without building a library first.

See clearly

Waveform, analyzers, level and loudness stay in view while you listen.

Shape lightly

Selection, cues, convert, rename and export without leaving the player.

A closer look

The interface stays close to the file list and the signal — enough to preview and trim quickly, without turning into a full editor.

Waveform and analyzers

Seek visually, switch analyzer modes, and keep an eye on spectral shape while you audition.

  • Waveform with playhead, selection and A-B region
  • Spectrogram, bars, frequency and waterfall views
  • Cursor readouts for time and frequency

Loudness and meters

Judge level and loudness in the same window you use to browse — useful before a handoff or a quick QC pass.

  • Peak / RMS / K-style output meters
  • Whole-file loudness analysis on demand
  • Refresh loudness for a selection from the file list

Folder workflow

Browse directories, filter the list, keep position when switching files, and jump back to the playing item.

  • Browser tree and details panel
  • Sequential, shuffle, loop one, stop after current
  • Multilingual UI and customizable hotkeys

Light editing tools

Mark, export and tidy files without a round-trip through a DAW for every small job.

  • Selection export with fade and format options
  • Cues, A-B loop, convert and batch rename
  • CSV export of the current list columns
